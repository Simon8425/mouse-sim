# Taste
- Prefers the smallest technically justified change — do not rewrite working systems; never stack compensating hacks when an experiment makes things worse (revert it instead). When the honest root cause turns out to be a model-fidelity limitation (e.g., too-coarse support discretization) whose proper fix is a large change with determinism/baseline/test implications, stop patching and report the precise diagnosis with options rather than piling on more heuristics that would make other cases unrealistically inert. - Treats previously established fixes/features as in-place until proven wrong — explicitly tells agents not to redo or revert prior rounds' work without evidence; even when an external AI's action plan demands reverting a fix, the fix stands until a real reproduction on current code disproves it.
